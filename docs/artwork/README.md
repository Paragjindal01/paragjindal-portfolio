# Flagship product artwork

Six conceptual covers generated with Higgsfield GPT Image 2.6 from an original contact sheet. The artwork depicts fictional equipment and visual concepts. Working product screenshots live under `public/lab-screenshots` and `relayops-ai/docs/screenshots`.

| Cover | Independent product |
| --- | --- |
| [Optical relay](relayops-ai.webp) | RelayOps AI |
| [Sensor and receiver](infrapilot-ai.webp) | InfraPilot AI |
| [Schematic cabinet](rackops.webp) | RackOps |
| [Accelerator board](gpuwatch.webp) | GPUWatch |
| [Power meter](powerops.webp) | PowerOps |
| [Document plates](localmind.webp) | LocalMind |

The covers are 690 × 460 WebP files. The optimized source plates are preserved with the [GitHub profile assets](https://github.com/Paragjindal01/Paragjindal01/tree/main/assets/artwork-sources). The cinematic website design is a separate workstream.
